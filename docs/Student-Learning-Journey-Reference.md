## 1. فلسفة المنصة

### 1.1 ليست منصة كورسات، ولا منصة شرح دروس

مدرستي هي **منصة تعلم موجه (Guided Learning Platform)**.

الفرق الجوهري:

| النموذج التقليدي | نموذج مدرستي |
|------------------|---------------|
| مشاهدة فيديو | رحلة إتقان درس |
| قراءة فقرة | قياس فهم الفقرة مباشرة |
| اختبار واحد في النهاية | قياس مستمر طوال الرحلة |
| المقارنة مع الآخرين | المقارنة مع الذات |
| "أكملت الدرس" | "أتقنت الدرس" |

### 1.2 السؤال الذي نبني عليه كل شيء

> **ما هو هدف الطالب عندما يدخل المنصة؟**

الهدف ليس:
- مشاهدة فيديو.
- قراءة فقرة.

الهدف هو:
> **إتقان درس.**

كل شاشة وكل زر وكل رسالة في المنصة يجب أن تخدم هذا الهدف.

### 1.3 الركائز الثلاث

1. **لا فجوات معرفية**: الطالب لا ينتقل إلى الفقرة التالية وهو يحمل فجوة في فهمه للفقرة السابقة — لأن كل فقرة تُقاس مباشرة بعد قراءتها.
2. **التقدم شعور وليس شريطًا**: كل شاشة تعطي الطالب إحساسًا بأنه في رحلة تتقدم، وليس مجرد استهلاك محتوى.
3. **التحسن فوق كل شيء**: الطالب يرى تقدمًا مقابل نفسه، لا مقارنة مع غيره، ولا رسائل "لقد أخطأت".

## 2. المبادئ الأساسية

تسري هذه المبادئ على كل صفحة وتصميم وقرار في النظام:

### 2.1 مبدأ الرحلة (Journey First)
- الطالب يشعر أنه يتقدم في رحلة تعلم، وكل خطوة لها هدف واضح.
- تجنب الصفحات الطويلة المليئة بالعناصر؛ استبدلها بخطوات متتابعة واضحة.

### 2.2 مبدأ القياس الفوري (Immediate Measurement)
- كل فقرة تنتهي بتقييم تكويني مباشر يقيس فهمها قبل الانتقال.
- لا يوجد محتوى يُستهلك دون قياس.

### 2.3 مبدأ التغذية الراجعة الإيجابية (Positive Feedback)
- لا نقول "لقد أخطأت" أبدًا.
- نقول "لقد تحسنت"، "يبدو أن الفقرة تحتاج مراجعة"، ونوجه الطالب للأمام.
- الرسائل تعيد التوجيه، لا تحكم على الطالب.

### 2.4 مبدأ المقارنة مع الذات (Self-Comparison)
- كل مقارنة تكون بين نتائج الطالب نفسه.
- لا توجد لوحات ترتيب ولا مقارنات مع الآخرين.

### 2.5 مبدأ التقدم المرئي (Visible Progress)
- التقدم يُعرض دائمًا وبكل وضوح (أشرطة، نسب مئوية، حالات ✓).
- كل حالة مكتملة/جارٍ/مقفلة مرئية في كل مستوى (وحدة، درس، خطوة).

### 2.6 مبدأ الفيديو كخيار لا كإجبار (Video as Optional)
- الفيديو الشامل مكمّل وليس أساسيًا.
- يظهر بوصفه "مراجعة سريعة اختيارية" وليس خطوة إجبارية في الرحلة.

### 2.7 مبدأ الأقل هو الأكثر (Minimalist Interface)
- الشاشة تعرض عنصرًا واحدًا أساسيًا في كل مرة.
- لا صفحات مزدحمة، ولا عناصر مشتتة أثناء التعلم.

## 3. بنية المحتوى

الهرم التعليمي من الأعلى إلى الأسفل:

```
المادة (Subject)
└── الوحدة (Unit)
    └── الدرس (Lesson)
        ├── التقييم القبلي (Pre-assessment)
        ├── الفقرة 1 (Paragraph)
        │   └── التقييم التكويني 1 (Formative Assessment)
        ├── الفقرة 2
        │   └── التقييم التكويني 2
        ├── الفقرة 3
        │   └── التقييم التكويني 3
        ├── الفيديو الشامل (Optional Video)
        └── التقييم النهائي (Final Assessment)
```

### 3.1 علاقة الوحدات
- الوحدات تُفتح بالتتابع: **لا تبدأ وحدة إلا بعد إنهاء السابقة**.
- الاستثناء: الوحدة الأولى تبدأ فورًا.

### 3.2 علاقة الدروس
- الدروس داخل الوحدة تُفتح بالتتابع: **لا يبدأ درس إلا بعد إتقان السابق**.
- كل درس يحتوي على تقييم قبلي واحد، وعدد من الفقرات، وتقييم نهائي واحد.

### 3.3 مكونات الدرس بالتفصيل

| المكون | إجباري؟ | الغرض |
|--------|---------|-------|
| التقييم القبلي | نعم | معرفة ما يعرفه الطالب مسبقًا |
| الفقرات | نعم | المحتوى التعليمي الأساسي |
| التقييم التكويني بعد كل فقرة | نعم | قياس فهم الفقرة مباشرة |
| الفيديو الشامل | لا | مراجعة سريعة اختيارية |
| التقييم النهائي | نعم | قياس الإتقان النهائي |

## 5. تفصيل كل شاشة

### 5.1 الصفحة الرئيسية — "مرحبًا، هذه رحلتك"

**الهدف**: أن يشعر الطالب فورًا أنه داخل رحلة، لا أمام قائمة دروس طويلة.

**العناصر (بالترتيب)**:

1. **الترحيب الشخصي**
   ```
   مرحبًا بلال 👋
   ```

2. **الموقع الحالي في الرحلة**
   ```
   📚 اللغة العربية
   الوحدة الثالثة
   التقدم 42%
   ━━━━━━━━━━━━━━
   ```

3. **الدرس التالي (البطل)**
   ```
   الدرس التالي
   المبتدأ والخبر
   [ابدأ الآن]
   ```

4. **ماذا يوجد أسفل ذلك؟** (بترتيب الأهمية)
   - آخر درس أكمله.
   - آخر تقييم (نتيجته وتطوره).
   - الإنجازات.

**قاعدة**: الصفحة الرئيسية لا تعرض قائمة محتوى، بل تعرض *الحالة*: أين أنا الآن؟ وما خطوتي التالية؟

### 5.2 صفحة المادة — "وحداتي وتقدمي فيها"

**الهدف**: رؤية الوحدات مع تقدمها وحالاتها بوضوح.

**العناصر**:
```
اللغة العربية
═══════════════════════
📘 الوحدة الأولى
██████████ 100%
✓ مكتملة
───────────────
📘 الوحدة الثانية
██████░░░░ 60%
───────────────
📘 الوحدة الثالثة
🔒 تبدأ بعد إنهاء السابقة
```

**قاعدة**: كل وحدة تعرض:
- اسمها.
- شريط تقدم مئوي.
- الحالة: `✓ مكتملة` / `جارٍ` / `🔒 مقفلة`.
- الوحدة المقفلة تظهر سبب القفل (تُنهي السابقة أولًا).

### 5.3 صفحة الوحدة — "دروسها"

**الهدف**: الدرس هو البطل هنا؛ تظهر الدروس في تسلسل مع حالاتها.

**العناصر**:
```
الوحدة الثالثة
══════════════════════
① المدخل
② المبتدأ والخبر
③ كان وأخواتها
④ إن وأخواتها
⑤ مراجعة الوحدة
══════════════════════
```

**حالات الدرس**:
- **مكتمل** (✓): درس تم إتقانه.
- **جارٍ** (●): الدرس الحالي النشط — يُفتح تلقائيًا.
- **مقفل** (🔒): لم يُتقن سابقه بعد.

### 5.4 صفحة الدرس — "نظرة عامة ثم ابدأ"

**الهدف**: لا تظهر المحتوى مباشرة؛ تعرض ملخص الرحلة ودعوة للبدء.

**العناصر**:
```
المبتدأ والخبر
━━━━━━━━━━━━━━━
⏱ 18 دقيقة
📖 3 فقرات
📝 3 تقييمات
🎥 فيديو
━━━━━━━━━━━━━━━
[ابدأ]
```

**قاعدة**: الصفحة لا تعرض محتوى الدرس، بل *ما سيراه الطالب في رحلته* (الزمن المتوقع، عدد الفقرات، عدد التقييمات، وجود فيديو)، ثم زر البداية.

### 5.5 داخل الدرس — الرحلة الكاملة

#### المرحلة 0: التقييم القبلي

```
التقييم القبلي
لنرَ ما تعرفه مسبقًا.
[ابدأ التقييم]
```

**بعد انتهاء التقييم القبلي** — لا تظهر نتيجة رقمية فقط، بل رسالة توجيهية:

- **إذا كان جيدًا**:
  ```
  أحسنت.
  يبدو أنك تعرف الأساسيات.
  لنبدأ الدرس.
  ```
- **إذا كان ضعيفًا**:
  ```
  لا بأس.
  سنشرح كل شيء خطوة بخطوة.
  ```

> **مهم**: نتيجة التقييم القبلي لا تمنع الطالب ولا تحكم عليه؛ هي مجرد تحديد نقطة البداية.

#### المرحلة 1: الفقرات والتقييمات التكوينية (قلب المشروع)

التناوب:
```
فقرة → تقييم تكويني → فقرة → تقييم تكويني → فقرة → تقييم تكويني
```

**شاشة الفقرة** (بسيطة، عنصر أساسي واحد في كل مرة):
```
عنوان الفقرة
──────────────
الصورة
──────────────
الشرح
──────────────
ريل (اختياري)
──────────────
[التالي]
```

**بعد الضغط على [التالي]** — لا ننتقل مباشرة إلى الفقرة التالية، بل إلى التقييم التكويني.

**شاشة التقييم التكويني**:
```
لنختبر فهمك.
3 أسئلة.
```

**منطق التقييم التكويني**:
- **نجح** → ينتقل إلى الفقرة التالية.
- **أخطأ** → لا يُعاد إلى بداية الدرس، بل تغذية راجعة توجيهية:

  ```
  يبدو أن الفقرة السابقة تحتاج مراجعة.
  [مراجعة الفقرة]
  ```

- زر **مراجعة الفقرة** يعيد عرض نفس الفقرة، ثم يعيد التقييم.
- لا عدد لا نهائي من المحاولات؛ الهدف الوصول للفهم لا احباط الطالب.

> **لماذا هذا أهم قرار في المشروع؟** لأنه يمنع تراكم الفجوات المعرفية. الطالب لا ينتقل لفقرة جديدة وهو يحمل سوء فهم.

#### المرحلة 2: الفيديو الشامل (اختياري)

```
إذا أردت مراجعة سريعة، شاهد الفيديو.
[مشاهدة الفيديو]  ← خيار
[المتابعة بدون]   ← خيار
```

**قاعدة**: الفيديو ليس إجباريًا وليس "خطوة" في الرحلة؛ هو أداة مراجعة اختيارية.

#### المرحلة 3: التقييم النهائي

```
التقييم النهائي
```

يقيس الإتقان الكامل بعد اكتمال الرحلة.

### 5.6 صفحة نهاية الوحدة

تُعرض بعد إتقان آخر درس في الوحدة:

```
🎉
أنهيت وحدة النحو.
━━━━━━━━━━━━━━
الدروس           5/5
━━━━━━━━━━━━━━
التقييمات        17
━━━━━━━━━━━━━━
[ابدأ الوحدة التالية]
```

**قاعدة**: نهاية الوحدة احتفاء بالرحلة المكتملة، مع ملخص كمي، ومسار واضح للأمام.

### 5.7 الإنجازات

- تظهر في الصفحة الرئيسية (ضمن القسم السفلي) وفي ملف الطالب.
- تمنح شعورًا بالتقدم طويل المدى.
- أمثلة: "أتممت أول وحدة".

## 6. منطق التقييمات والتغذية الراجعة

### 6.1 أنواع التقييمات

| النوع | متى | الوظيفة | هل يؤثر على التقدم؟ |
|-------|-----|---------|---------------------|
| القبلي | بداية الدرس | تحديد نقطة البداية | لا |
| التكويني | بعد كل فقرة | قياس فهم الفقرة فورًا | نعم (الانتقال) |
| النهائي | نهاية الدرس | قياس الإتقان الكلي | نعم (إكمال الدرس) |

### 6.2 منطق النجاح والفشل في التكويني

- **نجاح**: نسبة مئوية محددة أو أكثر (تُحدد في المواصفات التنفيذية لاحقًا).
- **فشل**: أقل من النسبة → رسالة مراجعة + زر إعادة الفقرة.
- لا "درجة صفر" ولا رسائل لوم.

### 6.3 منطق إكمال الدرس (الإتقان)

الدرس يُعتبر **مُتقنًا** عند اكتمال:
1. التقييم القبلي (بغض النظر عن نتيجته).
2. جميع الفقرات (مع اجتياز تكوينيها).
3. التقييم النهائي (بنسبة إتقان محددة).

### 6.4 نماذج رسائل التغذية الراجعة

| الحالة | الرسالة |
|--------|---------|
| اجتاز التكويني | "أحسنت، فهمت الفقرة." |
| لم يجتز التكويني | "يبدو أن الفقرة السابقة تحتاج مراجعة." |
| اجتاز القبلي | "أحسنت. يبدو أنك تعرف الأساسيات. لنبدأ الدرس." |
| لم يجتز القبلي | "لا بأس. سنشرح كل شيء خطوة بخطوة." |
| أكمل الدرس | "🎉 أحسنت، أنهيت الدرس." |
| أكمل الوحدة | "🎉 أنهيت وحدة النحو." |

## 7. حساب التقدم والإتقان

### 7.1 تقدم الوحدة
- نسبة مئوية = مجموع الدروس المُتقنة ÷ إجمالي الدروس.

### 7.2 تقدم المادة
- نسبة مئوية = مجموع الوحدات المُكتملة ÷ إجمالي الوحدات.

## 8. حالات العناصر ورسائل النظام

### 8.1 حالات الوحدة
| الحالة | العرض |
|--------|-------|
| مكتملة | `✓ مكتملة` + شريط 100% |
| جارية | شريط تقدم مئوي + خيار المتابعة |
| مقفلة | `🔒 تبدأ بعد إنهاء السابقة` |

### 8.2 حالات الدرس
| الحالة | العرض |
|--------|-------|
| مكتمل | ✓ |
| جارٍ | ● (الدرس النشط) |
| مقفل | 🔒 |

### 8.3 رسائل النظام العامة
- أسلوب موحد، إيجابي، يوجه للخطوة التالية.
- لا رسائل "خطأ" تحكم على الطالب.

## 9. ما يجعل المنصة مختلفة

**الخوف الأكبر**: أن تتحول المنصة إلى "فيديو + أسئلة" — وهذا موجود في عشرات المنصات.

**نقاط التميز التي تحمي من هذا التحول**:

1. **القياس المستمر بعد كل فقرة** — لا فجوات معرفية تتراكم.
2. **لغة "رحلة الإتقان"** — الواجهة تعطي إحساسًا بالتقدم لا بالمشاهدة.
3. **المقارنة مع الذات** — "لقد تحسنت" بدل "لقد أخطأت".
4. **الفيديو كخيار** — مكمل لا أساسي، عكس المنصات التقليدية.
5. **بساطة الشاشات** — عنصر واحد في كل مرة، لا ضوضاء.
6. **الاحتفاء بكل إنجاز** — نهاية درس، نهاية وحدة، إنجازات.

> **الوعد للطالب**: لا نتركك تنتقل وأنت تحمل فجوة معرفية، ونريك تقدمك مقارنةً بنفسك، لا بغيرك.

## 11. خطة تقسيم التوثيق

هذه الوثيقة تبقى **ثابتة** كمرجع للرؤية. عند الحاجة للتفاصيل التنفيذية، تُبنى وثائق منفصلة:

| الوثيقة | المحتوى | الحالة |
